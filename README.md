# Retail Sales Data Analysis – EDA

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of retail sales data using Python. The objective is to understand sales trends, customer demographics, and purchasing behaviour.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset inspection
- Missing value and duplicate analysis
- Descriptive statistical analysis
- Monthly and quarterly sales analysis
- Customer age and gender analysis
- Product/category sales analysis
- Correlation heatmap
- Customer spending analysis
- Business insights and recommendations

## Project Files
- `retail_sales_dataset.csv` – Dataset
- `EDA_Retail_Sales.ipynb` – Jupyter Notebook containing the analysis and visualizations
